# Clinton's Portfolio - Assignment 2

This project uses ExpressJS, NodeJS, and the EJS templating engine.
It is deployed on Render and hosted on GitHub.

## Design and Color Scheme
The website uses a blue, gold, black, and light neutral color scheme.
- Deep navy blue (#102A56)
- Gold (#D4AF37)
- Black (#151515)

## External Code & Libraries Cited
According to the assignment parameters, I have used the following external code/libraries:
1. **Bootstrap 5:** Used for responsive layout, cards, and form styling. (https://getbootstrap.com/)
2. **Font Awesome 6:** Used for the GitHub and LinkedIn footer icons. (https://fontawesome.com/)
3. **Express Generator:** The initial site structure was generated using the Express Generator with the `--views=ejs` flag.

All code was written and understood by me, and is documented with comments in the respective EJS and JS files.

## Routes
- `/` - Home page
- `/about` - About Me page
- `/projects` - Projects page
- `/contact` - Contact Me page
